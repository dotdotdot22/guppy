Guppy says:

Guppy uses the Matrix protocol for messaging and end-to-end encryption.

Message contents are encrypted between participants in the conversation. Guppy's ink messages and nudges are sent through the same encrypted conversation system.

Accounts connect to a Matrix homeserver, which handles message delivery and synchronisation between devices.

Guppy is also being developed as open-source software, so its source code can be inspected independently.

A more detailed privacy policy will be published before public testing begins.
